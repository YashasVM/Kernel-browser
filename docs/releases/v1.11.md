# Kernel Browser v1.11

## Extensions

- Install any Mozilla-signed extension: tap **Add to Firefox** on addons.mozilla.org, tap an
  `.xpi` link, or pick a file. Each install shows a permission prompt in plain English, with
  an option to run the extension in private tabs.
- One extension manager, used by both the toolbar and Settings: on/off toggles, the
  extension's own icon, and a details page with private-tab access, permissions, settings
  page, and Remove.
- Fixed: bundled uBlock Origin and Cookie-Editor were rejected by Gecko because `_locales/`
  was stripped from the APK.
- Fixed: extension popups didn't open, because the active tab was never reported to GeckoView.
- Extensions can open tabs (dashboards, welcome pages) and their options pages.
- Extension background scripts run out of process.

## Settings and menu

- New full-screen Settings with grouped sections, colored icons, current values on each row,
  and sub-pages that slide in and refresh when you come back.
- New settings: Autoplay (allow / block audio / block all), text size presets, homepage
  quick picks, granular Clear browsing data (history, site data, cache, permissions).
- Browser menu redesigned with quick actions (Bookmark, Share, Find, New tab). Duplicate
  toggles removed.
- The toolbar no longer disappears after 4 seconds; it hides while scrolling down.

## Tabs and start page

- Redesigned tab switcher: full-screen grid with Tabs / Private segments, live thumbnails,
  swipe or tap x to close, an undo bar, search, and Close all.
- New start page for new tabs and Home (search, top sites, bookmarks). It is script-free
  with a strict content policy; turn it off in Settings → Start page.

## Video

- Proper fullscreen: hides the toolbar and system bars, rotates landscape videos to
  landscape, and Back exits fullscreen.
- Screen stays on while a video plays.
- Autoplay is handled silently from the setting instead of a dialog per video.
- DRM (protected content) permission requests are labeled.

## Fixes and performance

- Downloads work on Android 8/9 (runtime storage permission, with a fallback folder);
  file names come from `Content-Disposition`.
- Enter on a hardware keyboard submits the address bar.
- Toolbar width and centering are corrected after rotation.
- Crashed or killed tab content processes reload instead of leaving a blank tab.
- Tab session saves are batched instead of written on every scroll event; fewer page
  screenshots per load; history writes are deduplicated; history and bookmarks are cached
  in memory; search suggestions are debounced on a single worker thread.
- Added `scripts/fetch_extensions.sh` for Linux, macOS, and CI.
- Back works on Android 13+ and Android 16 (predictive back): fullscreen exit, page
  history, and Settings sub-pages no longer get skipped.
- Pages can no longer open an extension install prompt without a tap.
- Install prompts left open when the app closes are cancelled cleanly; several downloads
  started during the storage permission prompt are all kept.
- Accessibility: toggle rows are one TalkBack stop that announces On/Off; touch targets
  are at least 48dp.
- CI: GitHub Actions runs unit tests and builds the ABI-split release APKs on every push.
