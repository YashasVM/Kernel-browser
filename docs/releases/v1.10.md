# Kernel Browser v1.10

Kernel Browser v1.10 focuses on making the Android browser shell feel smoother and easier to use day to day.

## Highlights

| Area | Change |
|---|---|
| **Settings motion** | Settings and nested sheets now use stable transform/opacity animation instead of snapping in from the wrong origin. |
| **Search suggestions** | The address bar shows Google recommendations while typing. |
| **History autofill** | Previously visited pages appear in address suggestions and can be opened directly. |
| **Safari-style chrome** | The suggestion tray sits above the bottom browser controls and respects the keyboard. |
| **Release APKs** | `v1.10` ships ABI split APKs for `arm64-v8a`, `armeabi-v7a`, and `x86_64`. |
